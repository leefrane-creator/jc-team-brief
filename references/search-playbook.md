# 搜索手册 · 查询模板与预算分配

## 信源金字塔（先分层，再搜索）

| 层级 | 信源 | 用于什么 | 可信度 |
|---|---|---|---|
| **L1 官方** | 俱乐部官网（含 club statement / official announcement）、俱乐部官方社媒、联赛官网、欧足联/亚足联官网 | 伤停官宣、名单、主帅任免、处罚 | 最高，可直接写「官宣」 |
| **L2 当地媒体** | 球队所在国的主流体育媒体（见下表） | 更衣室、舆论、战术细节、训练观察 | 高，多源交叉后接近官宣 |
| **L3 中文聚合** | 懂球帝、直播吧、新浪体育、虎扑 | 快速概览、赛前情报汇总 | 中，常为翻译+延迟，需回溯原始出处 |

**分层用法三条：**
1. 中文聚合源搜到的关键事实（尤其伤停），**尽量找到 L1/L2 的原始出处再定稿**；
   找不到就降级标注「中文聚合转述」
2. 官宣永远以当地语言原文为准——中文翻译常有延迟或口径偏差
3. 当地媒体的独家报道（更衣室内幕、帅位传闻）比中文聚合早 12–48 小时，
   比赛日当天差距最明显

## 官方信源的搜索打法

找俱乐部官网与官方声明：

```
<club English name> official injury update      (freshness: 7天)
<club English name> official announcement squad (freshness: 7天)
<league name> official match preview <home> vs <away>
```

要点：
- 大联赛球队官网基本都在 `<clubname>.com` 或 `.co.uk` / `.de` / `.es`，
  搜「club 全名 + 官网/official」一次即可定位
- 官方伤情声明通常在赛前 48–24 小时发布；开球前 1 小时看官方社媒的 matchday squad
- 联赛官网的 match preview 是免登录的结构化信息（近况/伤停/数据），L2 级性价比高

## 预算总则

| 层级 | 预算 | 说明 |
|---|---|---|
| 每队 | ≤ 3 次 | 优先级 1 > 2 > 3，前面搜透就不花后面 |
| 每场 | ≤ 7 次 | 两队 6 次 + 1 次可选（交锋/赛事背景） |
| 全量彩期 | 上限 200 次 | 超了说明查询设计有问题，先优化再继续 |

**省预算三招：**
1. 同一球队两天内二次分析 → 走缓存，只重搜新闻+伤停
2. 同联赛同轮的冷门场，两队合并一次搜索（如「塞尔塔 vs 赫塔费 伤停 首发」）
3. 强弱悬殊场（亚盘一球以上），弱队的教练/战术板块可从简，
   信息面价值集中在「弱队会不会摆大巴 + 强队轮不轮换」

**信源升级不额外烧预算：** L3→L1/L2 的溯源用 WebFetch 直取原文链接（不算搜索次数），
只有找不到原文、需要补一轮搜索时才计预算。

## 优先级 1 · 近 7 天新闻 + 伤停（必搜）

一次搜索同时喂板块 ①③④，这是性价比最高的一次：

```
第一轮（中文，快速建立全景）：
<队名> 最新消息 伤病 (freshness: 7天)

第二轮（当地语言，溯源+补最新）：
<club English name> injury news official    (freshness: 7天)
```

变体（第 1 次结果太稀时换）：
- `<队名> 伤停 名单`（freshness: 7天）
- `<队名> 更新 首发`（freshness: 3天，临场信息）
- `<club English name> team news preview`（freshness: 3天，L2 当地口径）

来源顺序：先用中文源建全景 → 关键伤停/名单类信息用当地语言源核验 →
官方声明优先于一切转述。

## 优先级 2 · 近期战绩 + 状态（必搜）

```
<队名> 近期战绩 近5场 (freshness: 30天)
```

要点：
- 已知比分可从 cn-football-data 拿，这里搜的是**战绩背后的叙述**：
  连胜时舆论怎么评价、连败后更衣室什么反应、有没有「选择性放弃」（联赛 vs 杯赛轮换）
- 舆论判读优先看 L2 当地媒体的赛后基调（headline 措辞本身就是舆论风向），
  中文聚合的「情绪」常滞后一天
- 判读要求写「走势」不堆比分：如「近5场3胜2负，但输的两场都输给前四，含金量存疑」

## 优先级 3 · 教练动态 + 战术（前两次没覆盖才搜）

```
<队名> 主教练 战术 风格 (freshness: 90天)
<coach name> tactics press conference   (freshness: 7天)
```

- 教练的**长期风格**不用新鲜（90 天窗口即可），但**换帅/帅位危机**必须新鲜（7 天）
- **赛前发布会是金矿**：主帅亲口说的伤情、轮换意图、战术表态，属 L1 级引用，
  各队发布会通常在开球前 1–2 天，当地媒体有全文或要点
- 帅位危机是高危信号：搜到「下课传闻/更衣室失控」直接升格为板块③的重点内容
- 新帅上任（≤ 3 场）要标注「风格样本不足，判读置信度低」

## 可选 · 交锋与赛事背景

```
<主队> vs <客队> 历史交锋 (freshness: 不限)
<赛事名> 本轮 背景 (freshness: 7天)   # 如「欧冠小组赛 出线形势」
```

只在以下情况花这一次：
- 双方近 3 次交锋有明显规律（如客队 5 年客场不胜主队）
- 赛事背景会改变动机（保级/争冠/欧战资格/杯赛练兵）

## 搜索结果质量自检

每队做完 3 次搜索后问自己：

1. 板块④有关键球员的**具体姓名 + 时点**吗？只有「多名主力伤缺」算失败，重搜一次变体
2. 板块④的伤停信息**溯源到 L1/L2 了吗**？纯 L3 转述的关键伤停必须补一轮当地语言搜索
3. 板块⑤写得出教练姓名吗？写不出 = 优先级 3 没搜到有效信息，换英文队名重试；
   开球前 48 小时内有发布会纪要就优先引用
4. 板块①的信息全是 7 天以内的吗？出现两周以上的旧闻说明 freshness 没设对

## 已知坑

- **音译名不一致**：同一球员在中文源有 2–3 种译名（如「格瓦迪奥尔/瓜迪奥尔」），
  搜不到时换译名变体，或直接用英文原名搜
- **Coaching 标签词陷阱**：搜「战术」容易命中游戏（FM/实况）内容，
  加「主帅」「教练」或球队全名规避
- **杯赛干扰**：周三搜「皇马 伤病」会混入周末联赛和下周欧冠两层信息，
  报告里必须区分「本场的伤停」与「其他赛事的伤停」
- **小语种盲区**：泰超/土超等联赛，当地媒体不易直接检索时，
  退回 L1（俱乐部官方社媒多语种发帖）+ 亚足联/欧足联官网 match page，
  不要硬凑 L2 垃圾源充数
- **官网被墙/加载慢**：部分俱乐部官网对国内访问不稳定，
  WebFetch 失败就改搜「site 限定 + cached 版本」，或引用当地媒体转述的官方口径
- **AI 生成内容混入**：新浪/网易等平台的部分前瞻文章为 AI 生成（文末带声明），
  其「预测首发」不可当情报，只取其中的官方信息转述部分
