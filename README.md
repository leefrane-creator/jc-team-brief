# jc-team-brief

**竞彩足球球队分析简报 Skill** — 针对当日全部竞彩足球比赛，自动搜索并生成双方球队的结构化中文简报。

一个纯搜索驱动的 Skill（无脚本依赖），每队固定五板块：新闻舆论 → 竞技状态 → 内部问题 → 伤停首发 → 教练战术，附每场关键影响因素速览。

> 仅整理公开信息面，不构成任何投注建议。

---

## 它解决什么问题

赛前看情报，最常见的四个坑：

1. **信息碎片化**。伤停散落在十几个 App 和网站里，凑齐一场比赛的两队信息要开十几个页面。
2. **时点不明**。「罗德里伤缺」——上周的伤缺和今天的伤缺是两回事，没时点的伤停信息不可信。
3. **传闻当事实**。单源小报的「据传」被转述两轮后变成了「确认」。
4. **预测当官宣**。开球前一切首发都是预测，AI 生成的前瞻文里的「预测首发」尤其不可当情报。

本 Skill 的对策：每条关键信息**强制带时点**、传闻与官宣**分层标注**、「预计首发」与「官宣首发」严格区分、信源三层金字塔溯源。

## 五板块固定结构

每个球队按固定顺序输出，空板块也保留（「未检索到公开信息」本身就是信息）：

1. **近期新闻热点与舆论动向**
2. **近期竞技状态及战绩影响**
3. **球队内部问题**（更衣室矛盾、伤病情况）
4. **关键球员首发与缺席**
5. **教练执教风格与潜在战术问题**

每场末尾附「本场关键影响因素速览」——只列变量，不写方向。

## 信源三层金字塔

| 层级 | 来源 | 用途 |
|---|---|---|
| **L1 官方** | 俱乐部官网/官方社媒、联赛官网、欧足联/亚足联 | 伤停官宣、名单、处罚 → 可标「官宣」 |
| **L2 当地媒体** | 球队所在国主流体育媒体 | 更衣室、舆论、战术细节，比中文聚合早 12–48 小时 |
| **L3 中文聚合** | 懂球帝、直播吧等 | 只用来建全景，关键伤停必须回溯 L1/L2 |

内置 11 个联赛当地信源速查表（英/西/意/德/法/荷/日/韩/澳/泰/土），搜索用球队当地语言外文名而非中文译名。

## 预算制搜索

- 每队 ≤ 3 次、每场 ≤ 7 次、全彩期上限 200 次——30 场全量跑也不失控
- L3 → L1/L2 的溯源用 WebFetch 直取原文，不计入搜索预算
- 48 小时内的球队简报缓存复用，只重搜新闻+伤停；联赛间歇期后全部作废
- 主帅赛前发布会（开球前 1–2 天）是 L1 级引用，伤情与轮换意图最准

## 专家校准层（v1.1.0）

- **顶尖专家会做而本 Skill 没要求的事**：把「没有新闻」当信号、看记者反复追问谁、建长期球队档案、读隐性变量（旅行/时差/欧战分心）、观察信息与盘口的背离
- **原始素材入手点**：训练场目击 → 球员个人社媒 → 官方文件原文 → 发布会逐字稿 → 当地语言原报道（翻译稿会丢限定语）
- **方法**：三角验证（转载链只算 1 个信源）、信源画像、时间线重建、基线对比（xG 差值而非「状态差」）、反烟雾弹过滤
- **第三方验证闭环**：报告页脚含「验证记录」区块，下期回填「预计首发命中率」，错例归因到信源等级；连续 2 期命中率 < 60% 自动降级报告置信度

```
jc-team-brief/
├── SKILL.md                      # 主文件：四步工作流 + 硬约束 + 专家校准
└── references/
    ├── search-playbook.md        # 搜索查询模板、信源速查表、已知坑

```

## 交付格式

- **HTML 简报**（默认）：深色卡片科技风，单文件自包含 CSS，零外部依赖；每场一张卡、两队左右分栏，伤停徽章语义色（红=确定缺席 / 橙=出战成疑 / 绿=复出 / 紫=停赛）
- Markdown 版按需生成
- 一个彩期一个文件，按竞彩编号排序，业务日跨自然日的凌晨场不漏

## 适用平台

WorkBuddy / Claude Code 等支持 Skill 机制的 AI Agent 环境。配合盘口采集类 Skill（如 [jc-odds-baseline](https://github.com/leefrane-creator/jc-odds-baseline)）可做信息面 × 盘口的背离交叉验证。
